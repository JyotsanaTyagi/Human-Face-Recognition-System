# Human-Face-Recognition-System
The Human Face Recognition System is an AI-based application that detects and identifies individuals from images or live video using computer vision and deep learning techniques. It is developed using tools like Python, OpenCV, and TensorFlow for face detection, feature extraction, and recognition.
It is an artificial intelligence–based application designed to automatically detect and recognize human faces from images or real-time video streams. It uses computer vision techniques to first locate faces within a frame and then extract unique facial features for identification. The system compares these extracted features with a pre-trained database to verify or recognize individuals accurately. It is commonly applied in security systems, attendance management, surveillance, and authentication processes.

The project is typically developed using **Python** as the core programming language along with **OpenCV** for image processing and face detection. Deep learning frameworks such as **TensorFlow** or **Keras** are used to train recognition models. Algorithms like Haar Cascade for detection and Convolutional Neural Networks (CNN) for feature extraction improve accuracy and performance. The system may also use a database like MySQL or SQLite to store facial data and user information. Overall, this project demonstrates practical implementation of machine learning, deep learning, and real-time image processing concepts.
